# Scroll Sync MVP

Инструмент для переводчиков: несколько вкладок (оригинал, черновик, публикация и т.п.) работают как одна рабочая поверхность. Без сервера и аккаунтов - всё локально в браузере (Chrome / Edge, Manifest V3).

## Установка распакованного расширения
### Edge
1. Откройте `edge://extensions`
2. Включите **Режим разработчика**
![alt text](https://github.com/adam-p/markdown-here/raw/master/src/common/images/icon48.png "Режим разработчика edge")
3. **Загрузить распакованное расширение** → распакованная папка расширения
![alt text](https://github.com/adam-p/markdown-here/raw/master/src/common/images/icon48.png "Загрузить расширение edge")

### Chrome

2. Включите **Режим разработчика**
![alt text](https://github.com/adam-p/markdown-here/raw/master/src/common/images/icon48.png "Режим разработчика chrome")

## Настройка

### Горячие клавиши

| Сочетание | Действие |
|----------|----------|
| `Alt+Shift+S` | Вкл/выкл синхронизацию активной группы |
| `Alt+Shift+G` | Создать группу из текущей вкладки |
| `Alt+Shift+A` | Добавить текущую вкладку в активную группу |

Переназначение: `chrome://extensions/shortcuts` (или `edge://extensions/shortcuts` в Edge).

### Режимы синхронизации

- **Процентный** - одинаковая относительная позиция (0–100%) на всех вкладках.
- **Якорный** - точки соответствия через **Добавить якорь** (сначала прокрутите каждую вкладку к нужному месту, затем нажмите кнопку). Нужно минимум **2 якоря**; пока их меньше, работает процентный режим.

### Режимы лидера

- **Активная вкладка** - источником становится та вкладка группы, которую вы крутите.
- **Фиксированный** - только выбранная вкладка управляет остальными.
