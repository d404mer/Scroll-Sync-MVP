Вкладки

    Групп пока нет. Откройте две страницы и нажмите Alt+Shift+G, затем добавьте вторую вкладку через Alt+Shift+A.

    Сначала создайте или выберите группу.

    Пиксельный — одинаковый сдвиг в px (по умолчанию). Процентный — одинаковая доля страницы.

    Для якорного режима нужно минимум 2 якоря (до этого используется процентный).

    Якоря: 0

    Масштаб вкладок

    100% — как лидер, 50% — вдвое медленнее, −100% — в обратную сторону.
