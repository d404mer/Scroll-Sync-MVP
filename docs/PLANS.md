ТЗ v0.1 — Scroll Sync MVP
Цель
Дать переводчику возможность одновременно работать с:
* AO3 → Google Docs
* Фикбук → Google Docs
* AO3 → Фикбук
* любой другой парой страниц
при помощи синхронного скролла между вкладками и окнами браузера.
________________


Основные требования
Поддерживаемые браузеры
* Google Chrome
* Microsoft Edge
________________


Тип расширения
Manifest V3
Локальное хранение данных.
Сервер отсутствует.
Регистрация аккаунта отсутствует.
________________


Функционал
F1. Создание группы вкладок
Пользователь может связать вкладки между собой.
Пример:
Группа #1


AO3
Google Docs
Фикбук


________________


F2. Синхронный скролл
При прокрутке одной вкладки остальные синхронно изменяют позицию.
Режимы:
Процентный
Источник: 35%


AO3 -> 35%
Docs -> 35%
Фикбук -> 35%


________________


Якорный
Пользователь вручную ставит точки соответствия.
AO3 глава
↓
Google Docs глава


Между точками положение рассчитывается автоматически.
________________


F3. Выбор ведущей вкладки
Режимы:
Активная вкладка
Лидером становится текущая активная вкладка.
________________


Фиксированная
Например:
AO3 всегда источник


________________


F4. Работа между окнами
Поддержка:
Монитор 1:
AO3


Монитор 2:
Google Docs


Скролл работает независимо от расположения окон.
________________


F5. Горячие клавиши
По умолчанию:
Alt + Shift + S
Вкл/выкл синхронизацию


Alt + Shift + G
Создать группу


Alt + Shift + A
Добавить вкладку в группу


Переназначаются через настройки браузера.
________________


Хранение данных
Сохраняются:
* группы вкладок
* URL
* настройки синхронизации
* якоря
После перезапуска браузера пользователь может восстановить сессию.
