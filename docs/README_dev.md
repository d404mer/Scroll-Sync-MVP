# Scroll Sync MVP

Расширение Manifest V3 для Chrome / Edge: синхронный скролл между вкладками и окнами для переводческих сценариев (AO3, Фикбук, Google Docs и произвольные страницы).

## Установка (разработка)

```bash
npm install
npm run build
```

1. Откройте `chrome://extensions` или `edge://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное расширение** → папка `dist/`

Для разработки с автопересборкой:

```bash
npm run dev
```

Загрузите расширение из пути, который выводит Vite/CRXJS (обычно `dist/`).

## Горячие клавиши (по умолчанию)

| Сочетание | Действие |
|----------|----------|
| `Alt+Shift+S` | Вкл/выкл синхронизацию активной группы |
| `Alt+Shift+G` | Создать группу из текущей вкладки |
| `Alt+Shift+A` | Добавить текущую вкладку в активную группу |

Переназначение: `chrome://extensions/shortcuts` (или edge://extensions/shortcuts в Edge).

## Логи расширения

- **Service worker (фон):** `chrome://extensions` → Scroll Sync → ссылка **Service worker** / **Просмотреть представления в службе** - откроется DevTools с Console.
- **Popup:** правый клик по иконке расширения → **Просмотреть всплывающее окно** (Inspect popup).
- **Content script (на странице):** F12 на самой вкладке (AO3/Docs/…) → Console; фильтр по контексту расширения, если сообщений много.

В Edge пути те же: `edge://extensions`.

## Быстрый старт

1. Откройте две страницы (например, глава AO3 + Google Docs / Фикбук / другая вкладка AO3).
2. На первой вкладке: **Создать группу** (или `Alt+Shift+G`).
3. На второй вкладке: **Добавить вкладку** (или `Alt+Shift+A`).
4. Убедитесь, что **Синхронизация включена**, затем прокрутите - вторая вкладка следует за вами.

### Режимы синхронизации

- **Процентный** - одинаковая относительная позиция (0–100%) на всех вкладках.
- **Якорный** - точки соответствия через **Добавить якорь** (сначала прокрутите каждую вкладку к нужному месту, затем нажмите кнопку). Нужно минимум **2 якоря**; пока их меньше, работает процентный режим.

### Режимы лидера

- **Активная вкладка** - источником становится та вкладка группы, которую вы крутите.
- **Фиксированный** - только выбранная вкладка управляет остальными.

## Хранение данных

Группы, URL, настройки синхронизации и якоря сохраняются в `chrome.storage.local`. После перезапуска браузера снова откройте те же URL - расширение сопоставит сохранённые адреса с новыми `tabId` (best-effort). Полное восстановление сессий (автооткрытие вкладок) - в v0.2.

## Адаптеры сайтов

| Сайт | Примечание |
|------|------------|
| Обычные страницы | Скролл `document` / `window` |
| archiveofourown.org | Предпочитает `#main` / `#workskin`, если они скроллятся |
| ficbook.net | Предпочитает основной контейнер контента, если он есть |
| docs.google.com | Поиск контейнера скролла (`.kix-appview-editor` и родители). Если UI Docs изменится, в popup может быть **Docs: контейнер скролла не найден** |

У Google Docs свой редактор; синхронизация скролла может работать хуже, чем на обычных страницах.
